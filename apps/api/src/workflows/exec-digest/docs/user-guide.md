# Using the Weekly Exec Digest

## Run it

1. Open **Workflows → Leadership → Weekly Exec Digest** in the Corporate
   organization and choose **New**.
2. Tick the departments to include (all are ticked by default).
3. Optionally pick the **week ending** date; leave it empty for the week
   ending today.
4. Choose **Write the digest**. It takes under a minute.

It also runs by itself every **Friday at 16:00** (Denver time) for every
department. Those runs appear in the list like any other.

## Read it

- **Result**: the company summary, the totals, and a card per department with
  its numbers, headline, summary and watch list.
- **Trace**: each writer's input (the numbers) and output.
- **Download → PDF, Word or Markdown** to share it.

## Admin

The schedule is an ambient trigger (**Ambient → Triggers**, "Weekly exec
digest"). Change or disable it there; the change applies at once.
