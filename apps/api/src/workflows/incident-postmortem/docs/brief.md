# Incident Postmortem

**From incident notes to a blameless postmortem and tracked action items.**

Paste the incident's timeline, chat excerpts and notes. Jev rates the
severity on one scale for every incident, a writer drafts the blameless
postmortem, and you approve the action items - each then becomes a task in
the team's work tracker, linked back to the postmortem.

## How it works

1. **Severity.** Jev's incident-severity rubric rates it SEV1, SEV2 or SEV3,
   and whether customer data was affected - the same way every time.
2. **Draft.** A writer produces the summary, impact, timeline, root cause,
   contributing factors, what went well and lessons - from your notes only,
   naming roles, not people.
3. **Action items.** An analyst proposes three to six concrete changes, each
   with an owner, priority and due window.
4. **Approve.** You keep, drop or reword each action item.
5. **Track.** Every approved item is created as a task (once, even if the
   run is retried), linked to the postmortem.

## What you get

- A complete postmortem to share, as PDF, Word or Markdown.
- Action items already in the tracker.
