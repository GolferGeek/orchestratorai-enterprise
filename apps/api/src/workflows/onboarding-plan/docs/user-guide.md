# Using New Hire Onboarding

1. Open **New Hire Onboarding** in the Human Resources organization.
2. Under **Record a new hire**, fill in the name, role, team, manager,
   location, employment type and start date. Add notes for anything special
   (a relocation, an accommodation, a hardware preference).
3. Choose **Record hire**. The hire appears under **Recent hires**, and their
   plan starts within a few seconds. Choose **Open plan** to follow it.
   To plan without the trigger, choose **Plan now** instead: the run records
   the hire itself.
4. When the run shows **Waiting for review**, open the review. Each request
   is an item: **Accept** it, **Reject** it, or **Modify** it to reword it.
   Then submit.
5. The result shows the welcome, the first week, 30/60/90 and each request
   with its task id. **Export** gives the plan as Markdown, Word or PDF to
   send to the new hire and their manager.

A hire has one plan. To change a plan, use **Restart from here** on the
draft step with an instruction, which starts a new run from the draft.
