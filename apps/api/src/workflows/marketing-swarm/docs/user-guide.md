# Using the Marketing Swarm

1. Open **Marketing Swarm** in the Marketing organization.
2. Fill in the brief: **Content type**, **Topic**, **Audience**, **Goal**,
   **Brand voice**, the points it **must cover**, and any **keywords**.
   Paste **Evidence on file** if the copy may make factual claims (studies,
   benchmarks, customer data). Without it, every factual claim counts as
   unsupported.
3. Choose the **Writers**, **Editors** and **Evaluators**, and how many
   **Rewrites** a draft may get (0-3). More writers give more choice but cost
   more.
4. Choose **Run the swarm**. The **Result** tab shows the board: each
   writer's draft, its score on every facet and each editor's verdict. It
   updates as drafts are revised.
5. When the run shows **Waiting for review**, the finalists are listed in
   standings order, each with its place for each evaluator.
   - **Approve all** makes the leader the winner.
   - To choose another, **Drop** the drafts above it. **Rewrite** a draft to
     polish it. The best-placed draft left wins.
   - **Reject**, with a reason, if none will do.
6. The result shows the winner, the standings and every version of every
   draft, with the coach's feedback. **Export** gives it as Markdown, Word or
   PDF.

**Configure** (admins) changes writers (persona and model), editors
(threshold and weights), evaluators (weights), facets and content types.
Runs already going keep the settings they started with.
