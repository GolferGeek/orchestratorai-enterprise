# Smoke test (5 minutes)

1. Sign in, pick **Marketing**, open **Marketing Swarm**, choose the
   **Spendline LinkedIn post** example, and run it with two writers, two
   editors and one rewrite.
2. The page stays on the run. The **Result** tab shows each writer's
   draft appearing, its facet scores, and the editors' verdicts.
3. The run waits for review. Every finalist has a place for each evaluator.
4. Drop the leader and approve. The result names the runner-up as the winner.
5. **Trace** lists write, check-0-..., the coach and rewrite units if a draft
   went back, and pick-winner.
6. **Export → PDF** shows the brief, the winner and the standings.
