# Using Invoice Exception Review

## Start a review

1. In **Finance**, open **Workflows → Accounts Payable → Invoice Exception
   Review** and choose **New**.
2. Pick the **purchase order** the invoice bills.
3. Either **upload the invoice** (PDF, Word or an image) or paste its text.
4. Choose **Review the invoice**. It takes under a minute.

## If it needs you

When there are exceptions the run stops on **Review**. You see each exception
(what, how much, which line), the invoice total, the budget owner and Jev's
verdict.

- **Approve all** pays the invoice despite the exceptions (they stay on record
  as approved exceptions).
- **Reject** needs a reason, which is recorded (for example "Wrong vendor
  entity - ask for a corrected invoice").

## Read the result

- **Result**: the decision, the exceptions, and each invoice line beside its
  PO line, price and quantity received.
- **Issues**: every exception with how the review settled it.
- **Trace**: the extractor's reading and Jev's answers.
- **Download** the decision as PDF, Word or Markdown.

## The rules

The tolerances come from FIN-POL-004 (Accounts Payable: Invoice Processing).
Ask the Finance Policy Assistant for the full policy.
