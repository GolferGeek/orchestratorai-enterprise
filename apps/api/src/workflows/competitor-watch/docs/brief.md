# Competitor Watch

**What changed on your competitors' pages, and which changes matter.**

You list the pages you follow - pricing, product, home. The watch fetches
each one, compares it with an earlier copy, and has Jev sort every change into
pricing, product, messaging, hiring or noise and decide whether marketing
should hear about it. Only the material changes are written up.

## How it works

1. **Fetch and compare.** Each page's text is compared, sentence by sentence,
   with the copy from the last run, or with the Internet Archive's copy from
   about 90 days ago. The comparison is code, not a model.
2. **Classify.** Jev reads each change and returns its type and whether it is
   material, with calibrated confidence. Cookie banners, dates and rotating
   testimonials are filtered out as noise.
3. **Write up.** A writer summarizes only the material changes, grouped by
   competitor, with prices and names quoted exactly.

## What you get

- The material changes with before and after text and the reason Jev gave.
- Which pages could not be fetched, and why.
- A PDF, Word or Markdown copy.

It runs every Monday morning against the previous week. Run it on demand
against the Internet Archive to see a quarter's changes at once.
