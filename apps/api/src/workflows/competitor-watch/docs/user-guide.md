# Using Competitor Watch

## Choose the pages

On the Competitor Watch page, under **Pages we follow**, add a page with
the competitor's name, what the page is (Pricing, Home, Product) and its
https:// address. Remove a page with its **Remove** button. Pages that need
JavaScript to show their text do not work well; pricing pages usually do.

## Run it

- **Since the last run** compares each page with its copy from the previous
  run. The first run of a new page only records it.
- **The last 90 days** compares each page with the Internet Archive's copy
  from about three months ago. Use it for a first look, or a quarterly review.

Choose **Check the pages**. It takes about a minute.

It also runs by itself every **Monday at 07:00** (Denver time), since the
last run.

## Read it

- **Result**: the write-up, each material change with its type, the text
  removed and added and Jev's reason, and the status of every page.
- **Trace**: the Jev verdict on every change, including those filtered as noise.
- **Download → PDF, Word or Markdown**.
